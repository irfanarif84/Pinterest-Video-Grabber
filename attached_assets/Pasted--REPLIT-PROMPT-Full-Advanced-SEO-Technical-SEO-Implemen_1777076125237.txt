## PART 1 — SERVER-SIDE RENDERING (CRITICAL)

The site MUST serve fully rendered HTML from the server so Googlebot can index it without executing JavaScript.

If using Node.js/Express:
```js
// server.js — serve fully rendered HTML for every route
app.get('/', (req, res) => {
  res.send(renderHomePage()); // returns complete HTML string, not a JS bundle
});
app.get('/pinterest-gif-downloader', (req, res) => res.send(renderGifPage()));
app.get('/pinterest-image-downloader', (req, res) => res.send(renderImagePage()));
app.get('/pinterest-to-mp3', (req, res) => res.send(renderMp3Page()));
app.get('/how-to-download-pinterest-videos', (req, res) => res.send(renderHowToPage()));
app.get('/sitemap.xml', (req, res) => { res.header('Content-Type','application/xml'); res.send(generateSitemap()); });
app.get('/robots.txt', (req, res) => { res.header('Content-Type','text/plain'); res.send(generateRobots()); });
```

Every page must render its full HTML content including all text, headings, and content — server-side — before sending to browser.

## PART 7 — HTTP SECURITY & PERFORMANCE HEADERS

In your Express server (or Replit's `.replit` config), add these response headers to EVERY request:

```js
app.use((req, res, next) => {
  // Security
  res.setHeader('X-Content-Type-Options', 'nosniff');
  res.setHeader('X-Frame-Options', 'SAMEORIGIN');
  res.setHeader('X-XSS-Protection', '1; mode=block');
  res.setHeader('Referrer-Policy', 'strict-origin-when-cross-origin');
  res.setHeader('Permissions-Policy', 'camera=(), microphone=(), geolocation=()');
  res.setHeader('Strict-Transport-Security', 'max-age=31536000; includeSubDomains; preload');

  // Performance
  res.setHeader('Vary', 'Accept-Encoding');

  // Cache static assets aggressively
  if (req.url.match(/\.(css|js|woff2|png|jpg|webp|svg|ico)$/)) {
    res.setHeader('Cache-Control', 'public, max-age=31536000, immutable');
  } else {
    res.setHeader('Cache-Control', 'public, max-age=3600, must-revalidate');
  }

  next();
});
```

Enable gzip/brotli compression:
```js
const compression = require('compression');
app.use(compression({ level: 6 }));
```

## PART 9 — CORE WEB VITALS OPTIMIZATIONS

### LCP (Largest Contentful Paint) — Target: < 2.5s
```html
<!-- Preload the hero section's LCP image or font -->
<link rel="preload" as="image" href="/og-image.jpg" />
<link rel="preload" as="font" href="/fonts/Syne-Bold.woff2" type="font/woff2" crossorigin />

<!-- Inline critical CSS directly in <head> — do NOT load it via external file -->
<style>
  /* Paste all above-the-fold CSS here inline */
</style>

<!-- Load non-critical CSS asynchronously -->
<link rel="stylesheet" href="/styles.css" media="print" onload="this.media='all'" />
```

### CLS (Cumulative Layout Shift) — Target: < 0.1
- Set explicit `width` and `height` on ALL images and video elements
- Reserve space for the download result section using `min-height`
- Never inject content above existing content after load

### FID / INP (Interaction to Next Paint) — Target: < 200ms
- Defer all non-critical JavaScript: `<script src="/app.js" defer></script>`
- Break up long tasks using `setTimeout` or `requestIdleCallback`
- Avoid layout-triggering JS in click handlers
